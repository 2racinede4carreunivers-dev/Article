## 2. Schéma de la base de données SQLite

La base de données générée par l'Orchestrateur 1 contient **4 tables principales** modélisant
la structure logique et sémantique de `methode_spectral.thy`.

### 2.1 Table `sections`

Représente la hiérarchie logique du fichier `.thy` selon le Pont Savard.

| Colonne        | Type    | Contrainte          | Description                                  |
|----------------|---------|---------------------|----------------------------------------------|
| `id`           | INTEGER | PRIMARY KEY AUTOINCREMENT | Identifiant unique                    |
| `code`         | TEXT    | NOT NULL UNIQUE      | Code court de la section (ex. `1/ms1`)       |
| `label`        | TEXT    | NOT NULL             | Libellé lisible de la section                |
| `description`  | TEXT    |                      | Description détaillée                        |
| `parent`       | TEXT    | FK → sections(code)  | Section parente (hiérarchie concentrique)    |
| `hol_anchor`   | TEXT    |                      | Point HOL d'ancrage principal                |
| `ligne_anchor` | INTEGER |                      | Ligne de référence dans le `.thy`            |

### 2.2 Table `points`

Représente chaque point formel du fichier `methode_spectral.thy` (lemme, définition, théorème…).

| Colonne           | Type    | Contrainte          | Description                                         |
|-------------------|---------|---------------------|-----------------------------------------------------|
| `id`              | INTEGER | PRIMARY KEY          | Identifiant unique                                  |
| `type`            | TEXT    | NOT NULL             | Type HOL : `lemma`, `definition`, `theorem`, `locale`, `axiomatization`, `consts`, `subsection`, `text` |
| `nom`             | TEXT    | NOT NULL             | Nom du point HOL                                    |
| `ligne`           | INTEGER | NOT NULL             | Numéro de ligne dans `methode_spectral.thy`         |
| `section_thy`     | TEXT    |                      | Section `.thy` d'appartenance                       |
| `subsection_thy`  | TEXT    |                      | Sous-section `.thy` d'appartenance                  |
| `section_logique` | TEXT    | NOT NULL, FK → sections(code) | Section logique Pont Savard            |

### 2.3 Table `relations`

Modélise les dépendances sémantiques entre points HOL.

| Colonne          | Type    | Contrainte                      | Description                         |
|------------------|---------|---------------------------------|-------------------------------------|
| `id`             | INTEGER | PRIMARY KEY                      | Identifiant unique                  |
| `point_source_id`| INTEGER | NOT NULL, FK → points(id)        | Point source de la relation         |
| `point_cible_id` | INTEGER | NOT NULL, FK → points(id)        | Point cible de la relation          |
| `type_relation`  | TEXT    | NOT NULL                         | Type : `VALIDE`, `DEPEND_DE`, etc.  |
| `description`    | TEXT    |                                  | Description de la relation          |

### 2.4 Table `concordances`

Mappe les sections de `methode_spectral.thy` vers `validation_hol_unifiee.thy`.

| Colonne          | Type    | Contrainte                      | Description                                     |
|------------------|---------|---------------------------------|-------------------------------------------------|
| `id`             | INTEGER | PRIMARY KEY AUTOINCREMENT        | Identifiant unique                              |
| `code`           | TEXT    | NOT NULL UNIQUE                  | Code de la concordance                          |
| `section_source` | TEXT    | NOT NULL, FK → sections(code)    | Section dans `methode_spectral.thy`             |
| `section_cible`  | TEXT    | NOT NULL, FK → sections(code)    | Section dans `validation_hol_unifiee.thy`       |
| `type_relation`  | TEXT    | NOT NULL                         | Nature de la concordance                        |
| `description`    | TEXT    |                                  | Description                                     |
| `hol_lemmes`     | TEXT    |                                  | Lemmes HOL associés                             |

## 4. Types de points HOL présents dans la validation

| Type HOL          | Rôle dans `methode_spectral.thy`                          |
|-------------------|-----------------------------------------------------------|
| `definition`      | Définition formelle d'un objet mathématique               |
| `lemma`           | Lemme intermédiaire démontré                              |
| `theorem`         | Résultat principal (ex. `reconstruction_premier_pos`)     |
| `locale`          | Contexte local Isabelle                                   |
| `axiomatization`  | Bloc d'axiomes fondateurs                                 |
| `consts`          | Déclaration de constantes                                 |
| `subsection`      | Marqueur structurel dans le fichier `.thy`                |
| `text`            | Bloc de texte explicatif                                  |

---

## 5. Types de relations entre points

| Type           | Sémantique                                                            |
|----------------|-----------------------------------------------------------------------|
| `VALIDE`       | Le point source valide la présence du point cible dans la logique     |
| `DEPEND_DE`    | Le point source dépend formellement du point cible                    |

## 6. Équation fondamentale du Pont Savard

$$\text{Ensemble} = \frac{1}{x} + \frac{1}{ms} + \frac{1}{t} = 1$$

Chaque cercle concentrique de `validation_hol_unifiee.thy` confirme que :
- **Tous les points** de `methode_spectral.thy` sont présents selon leur section logique.
- **Chaque ensemble** C1, C2, C3 valide la sémantique recherchée par l'auteur.
- La **contre-validation** garantit aux évaluateurs une lecture cohérente et orientée du fichier principal.
